# M5 sales data (Walmart, Kaggle)

Put these three files here (from https://www.kaggle.com/competitions/m5-forecasting-accuracy, Data tab):

- `sales_train_evaluation.csv` - daily unit sales per product per store (~1,941 days)
- `calendar.csv` - dates, weekdays, events/holidays, SNAP (benefit) days
- `sell_prices.csv` - weekly price per product per store

The CSVs are large and are not committed to git (see `.gitignore`). Do not put `kaggle.json` or any API key in this folder.
